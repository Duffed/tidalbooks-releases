# TIDAL Books

Android-App zum Hören von TIDAL-Hörbuchalben mit gespeichertem Fortschritt, Lesezeichen und Einschlaftimer.

APK-Downloads findest du unter [Releases](https://github.com/Duffed/tidalbooks-releases/releases).

Dieses Repository enthält ausschließlich Veröffentlichungen. Ein eigenes TIDAL-Konto mit passendem Abo ist erforderlich. Private, inoffizielle App; kein Produkt von TIDAL.
